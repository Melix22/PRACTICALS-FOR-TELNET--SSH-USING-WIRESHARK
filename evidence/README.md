# Evidence folder

Store `.pcapng` capture files here only if your course policy permits publishing them and you have checked them for sensitive information.

- `telnet/` — Telnet lab capture
- `ssh/` — SSH lab capture

Raw captures may contain usernames, IP addresses, and (for Telnet) readable test credentials or commands. Use test-only credentials. If uncertain, keep raw captures off GitHub and submit them through your instructor's approved channel.
